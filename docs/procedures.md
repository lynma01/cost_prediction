# Relevant Procedures

The [Product](products.md) is meant to be used in the following dental procedures for damaged and/or decaying teeth:

1. Installing crowns
   1. Amalgam
   2. Composite
2. Installing Inlays and/or Onlays
3. Fillings for living, but damaged/decayed teeth
4. Multi-coded services requiring both crowns and fillings

## Irrelevant Procedures

- Denture installations, and/or any procedures requiring the application of dental cement and/or adhesive *specifically* for fixing an dental implant to oral tissue is irrelevant to this product.

## Are there limitations due to Periodontal Disease Classification?

The [Product](products.md) can be used in the [above procedures](procedures.md#relevant-procedures) regardless of the periodontal disease classification (I -> IV) as defined in the [table below](procedures.md#periodontitis-staging).
